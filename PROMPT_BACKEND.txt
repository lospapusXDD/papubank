Necesito montar un backend completo para mi web app "PapusBank" que actualmente usa Firebase/Firestore. Quiero migrar a PostgreSQL + Node.js en mi PC Linux (CachyOS, Arch-based).

## NOTAS IMPORTANTES
- El hash de contraseña es: SHA256(password + salt) donde salt = hashSalt o nick
- Los IDs de documento Firestore son el nick del usuario (no auto-increment)
- Necesito que las tablas SQL usen el nick como PK donde Firestore lo usaba como doc ID
- Las operaciones financieras necesitan transacciones SQL (BEGIN/COMMIT)
- El frontend seguirá en GitHub Pages, solo cambio las llamadas fetch() para apuntar a mi backend

## PERMISOS DE LA PC LINUX
- La PC tiene permisos sudo (soy el dueño de la máquina)
- Necesito que configures la PC para que SIEMPRE esté encendida:
  - Deshabilitar sleep/hibernación: sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
  - Auto-login en consola (sin pedir contraseña en boot)
  - Si se apaga eléctricamente, que se encienda solo (BIOS: Power On After AC Loss o similar)
  - Que el servicio del backend (Node.js + PostgreSQL) arranque automáticamente al iniciar
  - Usar systemd para managing los servicios (postgresql y node app)
  - IP fija en la red local (para que el frontend siempre encuentre el backend)
  - Si tiene IP pública, configurar puertos. Si no, usar ngrok o similar para exponer la API
