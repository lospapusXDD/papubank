El túnel de Cloudflare responde pero da error 530 (código 1033). Eso significa que el túnel está levantado, pero el backend no está respondiendo desde la máquina donde corre el servidor.

Verificá en la PC donde corre el backend:

¿El servidor está corriendo? Después del corte de luz puede no haberse iniciado solo. Abrí una terminal y ejecutalo de nuevo (ej: node server.js o el comando que uses). Fijate que no tire errores.
¿En qué puerto escucha? El túnel apunta a localhost:PUERTO. Si el servidor escucha en un puerto distinto al que apunta cloudflared, da este error. Probalo con:
curl http://localhost:PUERTO/api/users
Si responde con {"error":"Token requerido"} (401) o algo similar, el servidor está OK.

¿El túnel apunta al puerto correcto? Debe ser algo como:
cloudflared tunnel --url http://localhost:PUERTO
con el mismo puerto del punto 2.

Cuando curl http://localhost:PUERTO/api/users responda, el error 530 desaparece y la página funciona. Avisame cuando esté listo.
