GET  /api/users          → retorna todos los usuarios de la tabla "users"
GET  /api/users/:nick    → retorna un usuario específico  
PUT  /api/users/:nick    → actualiza campos de un usuario

GET  /api/bank_accounts           → retorna todas las cuentas bancarias
PUT  /api/bank_accounts/:nick     → actualiza una cuenta bancaria

GET  /api/transactions            → retorna las transacciones
POST /api/transactions            → crea una transacción

GET  /api/board                   → retorna posts del board
POST /api/board                   → crea un post

GET  /api/chat                    → retorna mensajes del chat
POST /api/chat                    → envía un mensaje

GET  /api/polls                   → retorna encuestas
POST /api/polls                   → crea una encuesta

GET  /api/loans                   → retorna préstamos
POST /api/loans                   → crea un préstamo

GET  /api/messages                → retorna mensajes privados
POST /api/messages                → envía un mensaje privado

GET  /api/vaults                  → retorna bóvedas
GET  /api/vaults/:id              → retorna una bóveda
PUT  /api/vaults/:id              → actualiza una bóveda
POST /api/vaults/:id/letters      → agrega carta a bóveda
GET  /api/vaults/:id/letters      → retorna cartas de bóveda

GET  /api/flores_requests         → solicitudes de flores
GET  /api/events                  → eventos
GET  /api/reports                 → reportes
