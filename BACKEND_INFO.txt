El hash en la DB de solariswat fue calculado con hashSalt "emilio" (su nick anterior).
El frontend envía hashPass("nosexd103", "solariswat") pero el hash en la DB es hashPass("nosexd103", "emilio").

Solución: En el login, cuando reciba { nick, hash }, el backend debe:
1. Buscar el hashSalt del usuario en la tabla users
2. Recalcular el hash con: hashPass(password, hashSalt)
3. Comparar con el hash almacenado

O mejor: que el frontend envíe { nick, password } y el backend haga todo el proceso de hashing con el hashSalt correcto.

La función hashPass del frontend es:
function hashPass(p, salt) {
    salt = salt || '';
    const salted = salt + p + salt.split('').reverse().join('');
    let h = 5381;
    for (let i = 0; i < salted.length; i++) h = ((h << 5) + h) ^ salted.charCodeAt(i);
    let h2 = 0x811c9dc5;
    for (let i = 0; i < salted.length; i++) h2 = Math.imul(h2 ^ salted.charCodeAt(i), 0x01000193);
    return 's2_' + (h >>> 0).toString(36) + (h2 >>> 0).toString(36) + salted.length.toString(36);
}

Replicar ESTA función exacta en Node.js para el backend. NO usar SHA256.
