ANTIGRAVITY — Implementar backend 2FA TOTP (Google Authenticator) + cleanup

El frontend ya está listo y consume estos endpoints. Implementalos tal cual:

1. Login modificado — POST /auth/login:

Si el usuario tiene 2FA activado: responde { "twofaRequired": true, "tempToken": "..." } (SIN accessToken). tempToken: token firmado de un solo uso, expira en 5 min, vinculado al nick, max 5 intentos de verificación.
Si no: respuesta normal como ahora.
2. Confirmar 2FA — POST /auth/2fa/confirm body { "tempToken": "...", "code": "123456" }:

Valida el código TOTP o un código de respaldo.
Éxito → responde exactamente con la misma forma que /auth/login normal (accessToken, refreshToken, hash, campos del usuario).
Error → 401 "Código inválido".
3. Setup — POST /auth/2fa/setup (con auth header):

Genera secreto TOTP (usa otplib), lo guarda en users.twofa_secret como PENDIENTE.
Responde { "secret": "BASE32...", "otpauthUrl": "otpauth://totp/PapusBank:nicksin...?secret=...&issuer=PapusBank" }.
4. Activar — POST /auth/2fa/verify body { "code": "123456" }:

Valida el código contra el secreto pendiente, marca twofa_enabled = true, genera 10 códigos de respaldo (guardalos hasheados con SHA-256 en users.twofa_backup_codes, ej. formato BACKUP-XXXX-XXXX), invalida el secreto pendiente.
Responde { "backupCodes": ["BACKUP-XXXX-XXXX", ...10] } (SOLO se devuelven una vez).
5. Desactivar — POST /auth/2fa/disable body { "code": "..." }:

Requiere TOTP actual válido → twofa_enabled = false, borra secret y backup codes.
6. Regenerar backups — POST /auth/2fa/backup-codes body { "code": "..." }:

Requiere TOTP válido → genera 10 nuevos, responde { "backupCodes": [...] }.
7. GET /users/:nick → incluir "twofa_enabled": true/false (el frontend lee el estado de ahí).

8. Endpoints nuevos (POST /auth/2fa/setup, /auth/2fa/backup-codes, /auth/2fa/disable) → solo para usuario autenticado (JWT), solo sobre su propia cuenta.

Notas de seguridad: guarda twofa_secret en texto plano en DB está bien para este proyecto; cada backup code se usa una sola vez (márcalo usado en DB); verifica siempre con otplib authenticator.verify({token, secret}) y tolerancia ±1 step.
